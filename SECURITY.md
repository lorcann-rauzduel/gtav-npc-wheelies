# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.2.x   | ✅        |
| 1.1.x   | ✅        |
| < 1.1   | ❌        |

## Reporting Security Issues

**Do NOT report security vulnerabilities in public issues.**

Email the maintainer directly with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

## Scope

This mod runs as a script within GTA V via ScriptHookVDotNet.
- No network access
- No file system beyond game scripts folder
- No collection of user data

Security concerns should be minor, but report any suspicious behavior.
